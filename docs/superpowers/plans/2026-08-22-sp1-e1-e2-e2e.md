# SP1 E1/E2 E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Prove the canonical EPCIS compliance statement in a local SP1 guest, verify the resulting proof with the supplied Solidity verifier on Anvil, and measure a real Fabric acknowledgement-to-Anvil receipt path.

**Architecture:** Plonky3 remains the E1 AIR/recursion baseline. A separate SP1 guest reuses the canonical EPCIS bytes and checks the selected C1–C5 predicates in ordinary Rust, publishing only the epoch/state commitments and policy result. SP1 Groth16 verification is performed by Solidity before the anchor contract updates epoch state. Fabric is integrated as a local 2-org/2-peer smoke first; the paper will distinguish this smoke topology from the planned 3-Raft deployment.

**Tech Stack:** Rust workspace, SP1 v6.4.0 CPU prover, `ed25519-dalek` for guest signature checks, Hyperledger Fabric 2.5 chaincode/Gateway, Solidity SP1 Groth16 verifier, Anvil JSON-RPC.
